You can now run more than one agent in a workspace. Set up one for your main line and another for weekends, a second location or your website chat.

Each agent has its own phone number, greeting, voice and rules. It also keeps its own booking and transfer settings, so your weekend agent can take bookings while your main line sends urgent calls to the front desk. Every agent works from the same business details, knowledge, services and employees.

Open **Agents** and click **Add agent** to start. The new agent copies the settings of the one you added it from, so you only change what differs. Starter, Pro and Enterprise have no limit on agents.
