La page **Rendez-vous** affiche maintenant vos réservations dans un calendrier par jour, par semaine ou par mois. Cliquez sur un créneau libre pour réserver un client à cette heure. LobbyStack vérifie les disponibilités et envoie les mêmes textos de confirmation que lorsque votre agent réserve.

Chaque rendez-vous a deux types de notes. Votre agent peut lire les **Notes** à un appelant une fois qu'il l'a vérifié. Les **Notes internes** restent dans votre équipe : l'agent, le client et l'API ne les voient jamais.

Cliquez sur **Congés** pour fermer toute l'entreprise un jour férié, ou bloquer l'après-midi d'un employé. Personne ne peut réserver ce temps, votre agent compris.
