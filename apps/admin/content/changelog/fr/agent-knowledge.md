Chaque agent a maintenant une page **Connaissances spécifiques**, sous son nom dans **Agents**. Ajoutez-y des sites Web, des fichiers, des FAQ ou du texte, et seul cet agent s'en sert pour répondre. Votre ligne du soir peut donner le code de la porte après la fermeture, sans que votre accueil en parle.

La même page liste vos connaissances partagées, avec un interrupteur sur chaque source. Désactivez une source et cet agent cesse de s'en servir, tandis que les autres agents la gardent. Sur un site Web partagé, vous pouvez désactiver des pages une à une.

La page **Connaissances** montre maintenant chaque site Web sur une ligne avec son nombre de pages. Cliquez dessus pour désactiver des pages, les retirer ou réimporter le site. Cliquez sur **Sélectionner** pour supprimer, désactiver ou réimporter plusieurs sources à la fois.
