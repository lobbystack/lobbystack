Each agent now has a **Specific knowledge** page, under its name in **Agents**. Add websites, files, FAQs or text there, and only that agent answers from them. Your evening line can give out the after-hours door code while your front desk never mentions it.

The same page lists your shared knowledge with a switch on each source. Turn a source off and that agent stops using it, while every other agent keeps it. On a shared website, you can turn off single pages.

The **Knowledge** page now shows each website as one row with its page count. Click it to turn pages off, remove them or import the site again. Click **Select** to delete, turn off or re-import several sources at once.
