A rule can now apply to one channel only. Pick **Calls**, **Text messages**, **Website chat** or **Instagram** under **Channel** when you add or edit a rule. Leave it on **All channels** to keep it everywhere.

Use it for how your agent talks in each place. Ask for replies under 300 characters in texts, or have the agent spell out the address only on calls. The **Channel** column on the rules page shows where each rule applies.
