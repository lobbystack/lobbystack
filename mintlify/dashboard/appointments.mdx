The **Appointments** page lists upcoming bookings for the active business. Use it to review the schedule and check whether each booking reached the connected calendar.

## Review the schedule

Each row shows:

- Appointment time
- Customer name
- Service
- Assigned staff member
- Appointment status
- Calendar synchronization status

LobbyStack displays each appointment in its saved timezone.

## Refresh appointment data

Click **Refresh** to request the latest appointment list. The page also updates when LobbyStack receives an appointment event.

## Investigate a calendar issue

If the **Calendar** column shows a synchronization issue, check the Google Calendar connection under **Integrations**. Correct any account or permission problem before relying on live availability.

Connect [Google Calendar](/integrations/google-calendar) before allowing the receptionist to offer times. Configure caller cancellation and rescheduling under [Appointment changes](/agent/ai-settings/appointment-changes).
