**Instructions** tell an agent how to talk with customers on each kind of channel. Use them for tone, length and habits, such as "Keep answers short, and offer to book a visit." Use [Rules](/agent/rules) for what the agent does in a given situation, such as when to transfer.

Each agent has three instructions:

| Instruction | Where the agent follows it |
| --- | --- |
| **Calls** | Phone calls and calls from your browser |
| **Chats** | Website chat and Instagram direct messages |
| **Text messages** | Replies to texts |

## Write an instruction

<Steps>
  <Step title="Open Instructions">
    Click **Agents** in the sidebar, open the agent, and click **Instructions** in its menu.
  </Step>
  <Step title="Edit one">
    Click **Edit** beside **Calls**, **Chats** or **Text messages**, and write the instruction. Each holds up to 8,000 characters.
  </Step>
  <Step title="Save">
    Click **Save**. New calls and replies follow it.
  </Step>
</Steps>

To remove an instruction, clear the text and save. Only owners and admins can change instructions.

## Decide what goes in instructions

Keep instructions about how the agent talks:

- Write instructions the way you would brief a new teammate
- Keep facts about the business in [Knowledge](/settings/knowledge), where every agent can find them
- Give each agent its own instructions when they serve different callers, such as a shorter style for an after-hours line
