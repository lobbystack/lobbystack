The Docker Compose baseline runs LobbyStack's application, PostgreSQL, Redis, and a shared local-storage volume. Connect your own provider accounts for external capabilities.

## Required for live calls

<AccordionGroup>
  <Accordion title="Twilio" icon="phone">
    Twilio supplies phone numbers, call transfers, and phone verification. An Elastic SIP trunk sends calls for your numbers to OpenAI. Every number must sit on the trunk to answer calls. Keep the Twilio auth token server-side.
  </Accordion>
  <Accordion title="OpenAI" icon="waveform">
    OpenAI's GPT-Live model holds the conversation on phone and browser calls, and OpenAI hosts the audio. When the caller needs business data, such as openings or a booking, GPT-Live asks LobbyStack's worker, which answers with the receptionist agent. Your OpenAI project needs SIP enabled and an incoming-call webhook for phone calls.
  </Accordion>
</AccordionGroup>

## Knowledge and automation

<AccordionGroup>
  <Accordion title="OpenAI-compatible AI" icon="sparkles">
    The receptionist agent for website chat and calls runs on `gpt-6-luna` with high reasoning by default. To use another provider or a self-hosted runtime that implements the OpenAI-compatible chat and embeddings APIs, set the `AI_CHAT_*` and `AI_EMBEDDING_*` variables. The model must support tool calls, and embedding models must return exactly 1536 dimensions.
  </Accordion>
  <Accordion title="Firecrawl" icon="globe">
    Firecrawl imports public website content into the knowledge pipeline. You can omit it if operators only upload documents and enter knowledge manually.
  </Accordion>
</AccordionGroup>

## Optional integrations

- Google Calendar for availability and booking synchronization
- SMTP for verification, password reset, and operational email
- Polar for hosted billing and metered usage
- PostHog and OpenTelemetry for analytics, error tracking, traces, metrics, and logs
- AWS S3 or compatible storage for multi-host deployments
- MinIO through the optional `minio` Compose profile
- managed PostgreSQL and Redis instead of the included containers

Set `STORAGE_PROVIDER=s3` for AWS S3, MinIO, or another compatible service. Leave `S3_ENDPOINT` empty for AWS S3. MinIO requires its HTTP endpoint and `S3_FORCE_PATH_STYLE=true`.

Use the [environment variable reference](/self-hosting/environment-variables) for configuration names and the [Docker Compose guide](/self-hosting/docker-compose) for deployment steps.
