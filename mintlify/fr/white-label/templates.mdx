Un modèle copie la configuration d'une entreprise que vous avez déjà créée, pour que le prochain client du même secteur parte de celle-ci. Les propriétaires et les administrateurs enregistrent et suppriment les modèles sur la page **Modèles**, et toute votre équipe peut les voir. Vous choisissez un modèle quand vous créez une entreprise.

## Ce qu'un modèle copie

Un modèle garde les parties d'une configuration qui conviennent à toute entreprise du même type, et laisse de côté ce qui appartient à une seule entreprise :

| Un modèle copie | L'entreprise garde |
| --- | --- |
| Les réglages de la réceptionniste | Son nom, son fuseau horaire et son site Web, y compris les connaissances lues sur ce site |
| Les heures | Ses numéros de téléphone et son numéro de transfert |
| Les services et les règles | Son propriétaire, son équipe et son niveau d'accès |
| Les entrées de connaissances, les FAQ et les textes | Les employés affectés à chaque service |
| Les sites Web sur d'autres domaines | Un message d'accueil qui nomme l'entreprise |
| Les documents, sous forme de copies stockées | Les entrées, les sites Web et les documents que vous avez désactivés |

La page **Modèles** indique ce que chaque modèle configure, comme **Réglages de la réceptionniste**, **Heures** et le nombre de services, de règles, de sites Web, de documents, de FAQ et de textes.

## Enregistrer un modèle

Enregistrez un modèle depuis l'une ou l'autre de ces pages :

- Sur **Modèles**, cliquez sur **Enregistrer un modèle**, choisissez l'entreprise sous **Entreprise**, entrez un nom sous **Nom du modèle** et cliquez sur **Enregistrer le modèle**.
- Sur **Entreprises**, ouvrez le menu **Plus d'actions** d'une entreprise et choisissez **Enregistrer comme modèle**.

Le modèle garde sa propre copie de la configuration et des documents. Si vous modifiez l'entreprise plus tard, le modèle reste tel quel. Le journal d'audit de l'entreprise consigne qui a enregistré sa configuration.

L'enregistrement échoue quand l'entreprise a un réglage qu'un modèle ne peut pas contenir, comme une règle de plus de 4 000 caractères. Raccourcissez-le dans l'entreprise, puis enregistrez de nouveau.

## Créer une entreprise à partir d'un modèle

Dans le formulaire **Créer une entreprise**, choisissez le modèle sous **Modèle**. Le champ apparaît dès que vous en avez enregistré un. La nouvelle entreprise reçoit la configuration du modèle, avec le nom et le fuseau horaire que vous entrez dans le formulaire.

LobbyStack lit un échantillon de chaque site Web que liste le modèle. Pour lire le reste, ouvrez l'entreprise et utilisez sa page [**Connaissances**](/fr/agent/knowledge). Si LobbyStack ne peut pas appliquer le modèle, la console ne crée pas l'entreprise, et vous pouvez réessayer ou choisir un autre modèle.

Les modèles fonctionnent seulement depuis la console. Une clé de plateforme ne peut pas créer d'entreprise à partir d'un modèle.

## Supprimer un modèle

Ouvrez le menu **Plus d'actions** du modèle, choisissez **Supprimer**, puis cliquez sur **Supprimer le modèle**. Les entreprises que vous avez créées à partir de celui-ci gardent leur configuration.
