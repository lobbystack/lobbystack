La section **Agent** détermine le comportement de votre réceptionniste IA. Elle se divise en Paramètres IA, Connaissances, Services, Employés et Règles.

Les modifications s'appliquent aux nouveaux appels et aux nouvelles réponses du clavardage du site Web. Elles ne modifient pas les appels ni les messages passés.

## Comment la configuration est utilisée

LobbyStack prépare les réglages enregistrés de l'agent pour chaque appel en direct. Le comportement reste ainsi stable pendant toute la conversation.

Pour le clavardage du site Web, LobbyStack s'appuie sur le contexte actuel de l'entreprise et sur l'état enregistré de la conversation pour générer les réponses.

## Configuration minimale avant les vrais appelants

Avant de renvoyer de vrais appels, vérifiez que :

- Votre message d'accueil nomme votre entreprise et indique clairement à quoi l'appelant peut s'attendre.
- La langue client par défaut est celle que parlent la plupart de vos appelants, car les appels commencent dans cette langue.
- Un numéro de transfert est enregistré si vous voulez qu'un humain puisse prendre le relais en direct. Il doit se trouver dans un [pays que LobbyStack peut appeler](/fr/agent/ai-settings/overview#numéro-de-transfert-par-défaut).
- Vos entrées de connaissances couvrent les heures d'ouverture, l'adresse, les services, les prix, les politiques et les questions fréquentes des appelants.
- Vos services, vos employés et votre connexion Google Calendar sont prêts avant de compter sur la prise de rendez-vous ou les modifications de rendez-vous.
