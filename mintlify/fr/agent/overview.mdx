Un agent est l'IA qui répond à vos appels, à vos clavardages et à vos messages. Chaque espace de travail commence avec un agent. Avec un forfait payant, vous pouvez [en ajouter d'autres](/fr/agent/manage-agents), par exemple un pour les heures de fermeture ou un par emplacement.

Les modifications s'appliquent aux nouveaux appels et aux nouvelles réponses du clavardage du site Web. Elles ne modifient pas les appels ni les messages passés.

## Ouvrir un agent

Cliquez sur **Agents** dans la barre latérale. Avec un seul agent, la barre latérale passe au menu de cet agent. Avec plusieurs, la page **Agents** les liste, et chaque nom sous **Agents** ouvre son menu.

La ligne en haut du menu de l'agent, avec une flèche de retour et le nom de l'agent, réaffiche le menu principal. Avec plusieurs agents, cliquez sur le nom de l'agent en haut pour passer à un autre sur la même page.

## Ce que tous les agents partagent

Vos agents partagent les détails de l'entreprise, les connaissances, les services, les employés et les connexions de calendrier de l'espace de travail. Vous les modifiez une fois dans **Entreprise**, et chaque agent les utilise. La page **Commun à tous les agents** de l'agent mène à chacun :

- [Détails de l'entreprise](/fr/settings/business-details) : le résumé de l'entreprise, les heures d'ouverture, les langues, le fuseau horaire et la devise
- [Connaissances](/fr/settings/knowledge) : les entrées de texte, les documents et les importations de site Web
- [Services](/fr/settings/services) : ce que les appelants peuvent réserver
- [Employés](/fr/settings/employees) : les personnes que les appelants peuvent réserver ou demander
- [Connexions](/fr/integrations/overview) : Google Calendar, Cal.com et Calendly

## Comment LobbyStack utilise les réglages

LobbyStack prépare les réglages enregistrés de l'agent pour chaque appel en direct. Le comportement reste ainsi le même pendant tout l'appel. Pour le clavardage du site Web, LobbyStack lit les détails actuels de l'entreprise et la conversation jusque-là pour rédiger chaque réponse.

## Configuration minimale avant les vrais appelants

Avant de renvoyer de vrais appels, vérifiez que :

- Votre message d'accueil nomme votre entreprise et indique clairement à quoi l'appelant peut s'attendre
- La [langue client par défaut](/fr/settings/business-details#langue-client-par-défaut) est celle que parlent la plupart de vos appelants, car les appels commencent dans cette langue
- Un numéro de transfert est enregistré si vous voulez qu'une personne puisse prendre le relais en direct. Il doit se trouver dans un [pays que LobbyStack peut appeler](/fr/agent/calls-and-booking#numéro-de-transfert-par-défaut).
- Vos connaissances couvrent les heures d'ouverture, l'adresse, les services, les prix, les politiques et les questions fréquentes des appelants
- Vos services, vos employés et votre connexion de calendrier sont prêts avant de compter sur la prise de rendez-vous ou les modifications de rendez-vous
