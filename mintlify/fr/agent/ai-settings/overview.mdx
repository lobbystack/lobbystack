Ouvrez **Agent** > **Paramètres IA** pour modifier le comportement de base de la réceptionniste.

## Message d'accueil

Le message d'accueil est la phrase d'ouverture que votre réceptionniste prononce en répondant à un appel ou en commençant une conversation. Gardez-le court et précis.

Un bon message d'accueil comprend en général le nom de l'entreprise, une courte mention indiquant que l'appelant parle à la réceptionniste IA et une offre d'aide claire.

| Type d'entreprise | Exemple de message d'accueil |
| --- | --- |
| Clinique dentaire | Merci d'avoir appelé Bright Smile Dental. Je suis la réceptionniste IA. Comment puis-je vous aider ? |
| Salon de coiffure | Merci d'avoir appelé North Loop Salon. Je peux vous renseigner sur nos services et nos disponibilités, ou prendre un message pour l'équipe. |
| Services à domicile | Merci d'avoir appelé Peak HVAC. Je suis la réceptionniste IA. Vous appelez pour un service, un rendez-vous ou un problème urgent ? |
| Restaurant | Merci d'avoir appelé Maple Table. Je peux vous renseigner sur nos heures d'ouverture et les réservations, ou prendre un message pour le personnel. |

<Steps>
  <Step title="Ouvrez Paramètres IA">
    Dans la barre latérale du tableau de bord, allez dans **Agent** > **Paramètres IA**.
  </Step>
  <Step title="Modifiez le message d'accueil">
    Cliquez sur **Modifier** à côté de **Message d'accueil**, puis changez le texte.
  </Step>
  <Step title="Enregistrez">
    Cliquez sur **Enregistrer**.
  </Step>
</Steps>

## Résumé de l'entreprise

Le résumé de l'entreprise est ce que votre réceptionniste dit aux appelants qui demandent ce que fait ou offre l'entreprise. Il le lit avant chaque appel.

Vous n'avez pas à le rédiger. Quand vous ajoutez votre site web ou vos documents dans **Connaissances**, l'IA en rédige un résumé de deux à quatre phrases, dans votre langue client par défaut. Elle le réécrit quelques minutes après un changement de vos connaissances, et seulement si le contenu a changé.

Pour rédiger le vôtre, cliquez sur **Modifier** à côté de **Résumé de l'entreprise**, changez le texte et cliquez sur **Enregistrer**. L'IA ne modifie jamais un résumé que vous avez rédigé.

Pour revenir à un résumé de l'IA, cliquez sur **Modifier**, puis sur **Réécrire avec l'IA**. L'IA réécrit le résumé à partir de vos connaissances et vous indique quand c'est fait. Si vos connaissances ne disent pas encore ce que fait l'entreprise, le résumé reste tel quel.

## Heures d'ouverture

Votre réceptionniste réserve des rendez-vous seulement pendant vos heures d'ouverture. Si la réservation instantanée est activée et qu'aucune heure n'est définie, elle ne peut proposer aucun créneau : elle prend la demande de l'appelant en message pour votre équipe. Les paramètres de réservation affichent un avertissement tant que vous n'avez pas ajouté vos heures.

Vous n'avez pas à les saisir. Quand votre site web ou vos documents indiquent vos heures, l'IA remplit **Heures d'ouverture** quelques minutes après un changement de vos connaissances. Elle lit les heures dans n'importe quelle langue et enregistre une pause du midi comme deux plages le même jour. L'IA utilise seulement les heures que vos sources indiquent, et une note au-dessus des heures vous signale qu'elle les a remplies. Vérifiez-les.

Pour définir les heures vous-même, activez ou désactivez chaque jour, saisissez ses heures d'ouverture et de fermeture, puis cliquez sur **Enregistrer les heures**. Cliquez sur **Ajouter des heures** pour ajouter une deuxième plage autour d'une pause. L'IA ne modifie jamais les heures que vous avez enregistrées ici ou par l'API.

Pour les jours fériés et les autres périodes où vous êtes fermé, cliquez sur **Ajouter une fermeture** et indiquez quand vous fermez et rouvrez. Utilisez le fuseau horaire de votre entreprise, puis cliquez sur **Enregistrer les heures**. Votre réceptionniste ne réserve aucun rendez-vous pendant une fermeture. Elle dit aux appelants que l'entreprise est fermée à ce moment-là et leur propose un autre jour.

## Langue client par défaut

Les appels commencent dans votre **Langue client par défaut** : votre réceptionniste accueille les appelants dans cette langue. Quand un appelant demande une autre langue ou en parle une autre, votre réceptionniste passe à cette langue. Elle peut converser avec les appelants dans plus de 70 langues.

Le réglage **Langue client par défaut** prend en charge :

| Option | Valeur |
| --- | --- |
| Anglais | `en` |
| Français | `fr` |
| Espagnol | `es` |
| Serbe (alphabet latin) | `sr` |
| Allemand | `de` |
| Portugais (Brésil) | `pt` |
| Italien | `it` |
| Néerlandais | `nl` |

Choisissez la langue que parlent la plupart de vos appelants. Si vous n'avez pas modifié le message d'accueil, il passe au message d'accueil par défaut de la nouvelle langue.

<Note>
  Rédigez votre message d'accueil, vos connaissances, vos services et vos règles dans les langues que vos appelants utilisent le plus.
</Note>

## Devise

Choisissez dans **Devise** la devise de vos [prix de services](/fr/agent/services#prix). Votre réceptionniste annonce les prix dans cette devise. Si vous changez de devise plus tard, les montants que vous avez saisis restent les mêmes.

## Numéro de transfert par défaut

Le **Numéro de transfert par défaut** est le numéro que votre réceptionniste appelle quand elle transfère un appelant à une personne. Quand un appelant demande un [employé](/fr/agent/employees) qui a un numéro de téléphone, votre réceptionniste transfère plutôt l'appel à cet employé.

Choisissez un numéro qui répond pendant les heures d'ouverture. Si différentes équipes traitent différentes demandes, gardez le numéro par défaut comme destination de transfert la plus sûre et ajoutez des règles qui précisent quand transférer un appelant.

<Note>
  Les numéros de transfert doivent se trouver dans l'un de ces pays : États-Unis, Canada, Royaume-Uni, Australie, Nouvelle-Zélande, France, Allemagne, Espagne, Italie, Pays-Bas, Portugal, Mexique, Brésil, Israël, Inde, Japon ou Serbie. Les transferts vers des numéros d'autres pays n'aboutissent pas.
</Note>

Pendant un essai gratuit, votre réceptionniste transfère les appels uniquement vers le numéro de mobile que vous avez vérifié, et vous ne pouvez pas enregistrer un autre numéro. Passez à Starter ou à Pro pour le changer.

LobbyStack renvoie aussi les appels vers ce numéro quand vos minutes vocales sont épuisées ou que les dépassements atteignent votre plafond de dépenses. Sans ce numéro, ces appels vont au numéro de mobile que vous avez vérifié. Consultez [Utilisation et limites](/fr/billing/usage).

<Steps>
  <Step title="Entrez un numéro">
    Entrez le numéro de téléphone complet dans **Numéro de transfert par défaut**.
  </Step>
  <Step title="Enregistrez">
    Cliquez sur **Enregistrer** à côté du champ du numéro de transfert.
  </Step>
  <Step title="Ajoutez des règles au besoin">
    Utilisez **Agent** > **Règles** pour décrire quand la réceptionniste doit transférer l'appel, prendre un message ou demander les coordonnées pour un rappel.
  </Step>
</Steps>

<Note>
  Ajoutez un numéro de transfert si vous voulez qu'un humain puisse prendre le relais en direct. Sans numéro, la réceptionniste note les coordonnées pour un rappel ou un suivi, et votre équipe peut répondre depuis le tableau de bord.
</Note>

## Modifications de rendez-vous

Utilisez **Modifications de rendez-vous** pour choisir si la réceptionniste IA peut annuler ou déplacer des rendez-vous automatiquement.

Vous pouvez aussi exiger un code unique par SMS ou un code PIN sur le clavier avant toute modification d'un rendez-vous.
