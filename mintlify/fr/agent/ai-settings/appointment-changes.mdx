Quand un appelant doit annuler ou déplacer un rendez-vous, LobbyStack peut traiter la demande pendant l'appel.

Votre équipe n'a plus à lire un message, vérifier le calendrier et répondre à la main : la réceptionniste IA peut retrouver le rendez-vous, confirmer la demande et mettre à jour la réservation pour vous.

## Ce que l'IA peut faire

LobbyStack peut aider vos clients à :

- Retrouver leur prochain rendez-vous.
- Annuler un rendez-vous dont ils n'ont plus besoin.
- Déplacer un rendez-vous à un autre créneau disponible.
- Confirmer la modification avant qu'elle soit appliquée.
- Régler la demande pendant l'appel.

Cette fonction vise les modifications de rendez-vous courantes, qui détournent habituellement votre équipe de tâches plus importantes.

## Confirmation intégrée avant toute modification

Une simple demande en passant ne suffit pas pour modifier un rendez-vous. LobbyStack demande assez de détails pour s'assurer que le client modifie le bon rendez-vous.

Par défaut, la réceptionniste utilise :

- Le numéro de téléphone de l'appel.
- Le nom du client.
- Un détail du rendez-vous, comme l'heure ou le service.
- Une confirmation finale claire avant d'annuler ou de déplacer le rendez-vous.

Si la réceptionniste ne parvient pas à confirmer le rendez-vous avec certitude, elle ne fait pas la modification automatiquement. Elle peut plutôt transmettre la conversation à votre équipe.

<Note>
  LobbyStack vous aide à appliquer des étapes de confirmation cohérentes, mais ne remplace pas votre propre analyse juridique ou de confidentialité. Configurez le niveau de vérification adapté à votre entreprise, à votre région et au type de rendez-vous.
</Note>

## Choisir comment vérifier l'appelant

Si votre entreprise veut une garantie supplémentaire, **Vérification de l'appelant** ajoute une étape avant que l'IA modifie un rendez-vous :

| Option | Ce que fait l'appelant |
| --- | --- |
| **Numéro de téléphone et détails du rendez-vous** | Il appelle du numéro utilisé pour réserver et indique l'heure ou le service du rendez-vous. C'est l'option par défaut. |
| **Code unique par SMS** | Il lit aussi un code que la réceptionniste envoie par SMS à ce numéro. |
| **Code PIN sur le clavier** | Il saisit aussi un code PIN sur le clavier de son téléphone. Votre équipe définit le code PIN de chaque client, sans aucun SMS. |

Une vérification plus stricte est utile pour les rendez-vous sensibles, de grande valeur ou soumis à des politiques internes plus strictes.

### Configurer les codes PIN

Avec **Code PIN sur le clavier**, la réceptionniste demande à l'appelant de saisir son code PIN sur le clavier de son téléphone, puis d'appuyer sur la touche dièse (#). Le code PIN n'est jamais transmis à l'IA ni à la transcription de l'appel, et la réceptionniste refuse un code PIN dit à voix haute.

<Steps>
  <Step title="Ouvrez le contact">
    Dans la barre latérale du tableau de bord, allez dans **Contacts** et ouvrez la fiche du client.
  </Step>
  <Step title="Définissez le code PIN">
    Dans l'onglet **Détails**, sous **Code PIN**, sélectionnez **Définir un code PIN**. Saisissez de 4 à 8 chiffres, ou sélectionnez **Générer**, puis enregistrez.
  </Step>
  <Step title="Communiquez le code PIN au client">
    LobbyStack enregistre le code PIN de façon sécurisée et ne peut plus l'afficher. Si le client l'oublie, définissez-en un nouveau.
  </Step>
</Steps>

Pour donner un code PIN à de nombreux clients à la fois, utilisez la [ligne de commande](/fr/api/cli) ou l'[API](/fr/api/overview). `lobbystack contacts generate-pins --all` crée un code PIN pour chaque contact qui a un numéro de téléphone et aucun code PIN, et affiche chaque code PIN cette seule fois. `lobbystack contacts set-pins` définit les codes PIN que vous choisissez. Dans l'API, ce sont `POST /contacts/passcodes/generate` et `POST /contacts/passcodes`.

L'appelant peut essayer son code PIN 3 fois par modification. Après 5 codes PIN erronés d'affilée, même sur plusieurs appels, le code PIN est bloqué et la fiche contact l'indique. Définir un nouveau code PIN le débloque.

Un appelant sans code PIN, ou dont le code PIN est bloqué, ne peut pas modifier ses rendez-vous par téléphone. La réceptionniste transmet plutôt sa demande d'annulation à votre équipe.

<Warning>
  Sur une installation auto-hébergée de LobbyStack, les codes PIN sont vérifiés avec le `OTP_HASH_SECRET` du serveur (ou `ENCRYPTION_KEY` s'il n'est pas défini). Si ce secret change, tous les codes PIN enregistrés cessent de fonctionner et doivent être redéfinis.
</Warning>

## Mises à jour automatiques du calendrier

Quand une modification est approuvée, LobbyStack met à jour la fiche du rendez-vous et synchronise le changement avec votre calendrier connecté.

Pour une annulation, LobbyStack marque le rendez-vous comme annulé, puis met à jour ou supprime l'événement selon la connexion au calendrier.

Pour un déplacement, LobbyStack vérifie les disponibilités avant de proposer un nouveau créneau. Si le créneau est libre, LobbyStack déplace le rendez-vous et actualise la synchronisation avec le calendrier.

<Tip>
  Connectez Google Calendar avant de compter sur le déplacement automatique des rendez-vous. LobbyStack évite ainsi de proposer des créneaux déjà occupés.
</Tip>

## Activer ou désactiver les modifications de rendez-vous

Vous décidez si la réceptionniste peut annuler ou déplacer des rendez-vous, et comment elle vérifie l'appelant.

<Steps>
  <Step title="Ouvrez Paramètres IA">
    Dans la barre latérale du tableau de bord, allez dans **Agent** > **Paramètres IA**.
  </Step>
  <Step title="Trouvez les modifications de rendez-vous">
    Faites défiler jusqu'à **Modifications de rendez-vous**.
  </Step>
  <Step title="Choisissez ce que l'IA peut faire">
    Activez ou désactivez l'annulation et le déplacement.
  </Step>
  <Step title="Choisissez le niveau de vérification">
    Choisissez une option dans **Vérification de l'appelant** si vous voulez une vérification plus stricte.
  </Step>
  <Step title="Enregistrez">
    Enregistrez vos modifications.
  </Step>
</Steps>

## Configuration recommandée

Pour offrir la meilleure expérience à vos clients :

- Ajoutez des services clairement décrits pour que les clients puissent dire ce qu'ils ont réservé.
- Connectez Google Calendar pour que LobbyStack puisse vérifier les disponibilités et synchroniser les modifications.
- Tenez votre numéro de transfert à jour pour les cas qui demandent une vérification humaine.
- Utilisez un code unique par SMS ou un code PIN sur le clavier pour les rendez-vous sensibles ou de grande valeur.
