Un canal est un moyen par lequel les clients vous joignent : un numéro de téléphone, un widget de site Web ou votre compte Instagram. Chaque canal répond comme un seul agent, avec son message d'accueil, sa voix, ses instructions et ses règles.

Pour voir les canaux d'un agent, cliquez sur **Agents** dans la barre latérale, ouvrez l'agent et cliquez sur **Canaux** dans son menu. Le chiffre à côté de **Canaux** les compte. Un point indique que l'agent n'en a pas encore : personne ne le joint.

## Types de canaux

- **Numéro de téléphone** : les appelants qui composent votre numéro LobbyStack. Consultez [Gérer le numéro de téléphone de votre entreprise](/fr/agent/phone-number).
- **Widget de site web** : les visiteurs qui clavardent ou appellent depuis votre site Web. Consultez [Ajouter le widget de site Web](/fr/agent/widget).
- **Instagram** : les personnes qui envoient un message privé à votre entreprise. Consultez [Répondre aux messages privés Instagram](/fr/integrations/instagram).

## Transférer un canal à un autre agent

Avec plus d'un agent, les propriétaires et les administrateurs peuvent transférer un canal d'un agent à un autre.

<Steps>
  <Step title="Ouvrez l'agent du canal">
    Ouvrez l'agent qui répond au canal en ce moment, puis cliquez sur **Canaux**.
  </Step>
  <Step title="Choisissez le nouvel agent">
    Cliquez sur **Transférer à** à côté du canal et choisissez l'agent qui doit y répondre.
  </Step>
  <Step title="Confirmez">
    Cliquez sur **Transférer**.
  </Step>
</Steps>

Le nouvel agent répond dès lors. Les conversations ouvertes sur ce canal le suivent : le nouvel agent reprend donc tout clavardage en cours. Les appels et les conversations passés restent sous l'agent qui les a traités.

Vous pouvez aussi partir de l'agent qui doit répondre. S'il n'a pas de numéro, ses **Canaux** affichent **Transférer ici** sous **Numéro de téléphone**, avec les numéros auxquels répondent vos autres agents. La ligne **Instagram** affiche **Transférer ici** quand un autre agent répond au compte.

Un numéro de téléphone peut seulement passer d'un agent à un autre. Pour abandonner un numéro, ouvrez sa page avec **Gérer**.

## Déconnecter un canal

Cliquez sur **Déconnecter** à côté d'un widget de site Web ou du compte Instagram, puis confirmez. Un widget déconnecté arrête le clavardage sur chaque site Web qui l'utilise. Un compte Instagram déconnecté ne reçoit plus de réponses à ses messages privés.

## Canaux d'un agent en pause

Avec Free, seul l'agent par défaut répond. Un [agent en pause](/fr/agent/manage-agents#agents-en-pause-sur-free) garde ses canaux, et l'agent par défaut y répond jusqu'à ce que vous changiez de forfait.
