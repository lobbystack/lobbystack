Les **Instructions** indiquent à un agent comment parler aux clients sur chaque type de canal. Utilisez-les pour le ton, la longueur et les habitudes, par exemple « Répondez brièvement et proposez de prendre rendez-vous. » Utilisez les [Règles](/fr/agent/rules) pour ce que l'agent fait dans une situation précise, par exemple quand transférer un appel.

Chaque agent a trois instructions :

| Instruction | Où l'agent la suit |
| --- | --- |
| **Appels** | Les appels téléphoniques et les appels depuis votre navigateur |
| **Clavardage** | Le clavardage du site Web et les messages privés Instagram |
| **Textos** | Les réponses aux textos |

## Rédiger une instruction

<Steps>
  <Step title="Ouvrez Instructions">
    Cliquez sur **Agents** dans la barre latérale, ouvrez l'agent et cliquez sur **Instructions** dans son menu.
  </Step>
  <Step title="Modifiez-en une">
    Cliquez sur **Modifier** à côté de **Appels**, **Clavardage** ou **Textos**, puis rédigez l'instruction. Chacune contient jusqu'à 8 000 caractères.
  </Step>
  <Step title="Enregistrez">
    Cliquez sur **Enregistrer**. Les nouveaux appels et les nouvelles réponses la suivent.
  </Step>
</Steps>

Pour retirer une instruction, effacez le texte et enregistrez. Seuls les propriétaires et les administrateurs peuvent modifier les instructions.

## Choisir ce qui va dans les instructions

Gardez dans les instructions la façon dont l'agent parle :

- Rédigez les instructions comme si vous informiez un nouveau collègue
- Gardez les faits sur l'entreprise dans les [Connaissances](/fr/settings/knowledge), où chaque agent peut les trouver
- Donnez à chaque agent ses propres instructions quand ils servent des appelants différents, par exemple un style plus court pour une ligne après les heures d'ouverture
