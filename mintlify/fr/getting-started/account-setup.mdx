Votre compte LobbyStack vous donne accès au tableau de bord et aux espaces de travail de votre entreprise. Ce guide explique l'inscription, la connexion, le changement d'adresse courriel et le changement de mot de passe.

## Créer un compte

<Steps>
  <Step title="Ouvrez la page d'inscription">
    Ouvrez la page d'inscription de LobbyStack. Vous pouvez y accéder depuis la page d'accueil en cliquant sur **Essayer gratuitement**, ou en allant directement à l'URL d'inscription.
  </Step>

  <Step title="Entrez votre adresse courriel et votre mot de passe">
    Indiquez l'adresse courriel que vous voulez utiliser pour votre compte et choisissez un mot de passe.

    Choisissez un mot de passe robuste et unique. LobbyStack impose une longueur minimale et des exigences de complexité.
  </Step>

  <Step title="Envoyez le formulaire">
    Cliquez sur **Créer le compte**. LobbyStack crée le compte et ouvre le parcours de configuration de l'entreprise.

    Consultez le [guide de démarrage](/fr/quickstart) pour suivre la configuration étape par étape.
  </Step>
</Steps>

## Se connecter

Ouvrez la page de connexion de LobbyStack et entrez votre adresse courriel et votre mot de passe. Si vous avez oublié votre mot de passe, cliquez sur **Mot de passe oublié?**. LobbyStack vous envoie par courriel un lien de réinitialisation qui ouvre le formulaire de mot de passe.

## Modifier les réglages de votre compte

Une fois connecté, allez dans **Réglages** > **Compte**. Cette page vous permet de modifier le nom de votre entreprise, votre adresse courriel et votre mot de passe.

### Nom de l'entreprise

Le nom de votre entreprise apparaît dans votre tableau de bord. La réceptionniste IA l'utilise aussi pour accueillir les appelants, sauf si vous remplacez le message d'accueil par un texte personnalisé.

1. Dans **Réglages** > **Compte**, repérez le champ **Nom de l'entreprise**.
2. Modifiez le nom et cliquez sur **Enregistrer**.

La modification s'applique immédiatement.

### Adresse courriel

Un changement d'adresse courriel doit être confirmé.

1. Dans **Réglages** > **Compte**, repérez le champ **Courriel**.
2. Entrez votre nouvelle adresse courriel et cliquez sur **Enregistrer**.
3. LobbyStack envoie un courriel de confirmation à la nouvelle adresse. Ouvrez-le et cliquez sur le lien de confirmation.
4. Votre adresse courriel est mise à jour dès que vous confirmez.

<Note>
  Tant que vous n'avez pas cliqué sur le lien du courriel de confirmation, votre compte continue d'utiliser votre adresse d'origine. Si le courriel n'arrive pas après quelques minutes, vérifiez votre dossier de courrier indésirable.
</Note>

### Mot de passe

1. Dans **Réglages** > **Compte**, repérez la section **Mot de passe**.
2. Entrez votre mot de passe actuel, puis entrez et confirmez le nouveau.
3. Cliquez sur **Enregistrer**.

Votre session en cours reste active après un changement de mot de passe. Consultez la page [sécurité du compte](/fr/settings/account) pour connaître la démarche actuelle.
