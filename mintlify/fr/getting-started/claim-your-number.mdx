Vous choisissez votre numéro LobbyStack pendant la configuration. Quand quelqu'un appelle ce numéro, votre agent IA répond. Sans forfait payant, le numéro est gratuit pendant 14 jours. Les forfaits Starter et Pro incluent un numéro.

## Qu'est-ce qu'un numéro dédié ?

Un numéro dédié est un vrai numéro de téléphone attribué exclusivement à votre entreprise sur LobbyStack. Les appelants le composent comme n'importe quel autre numéro. L'agent IA répond, les accueille et traite l'appel selon vos réglages.

Vous pouvez utiliser ce numéro comme ligne principale de votre entreprise, ou garder votre numéro actuel et y renvoyer les appels. Votre agent IA traite tous les appels qui arrivent sur le numéro LobbyStack.

## Choisir votre numéro pendant la configuration

L'étape du numéro, **Choisissez le numéro de votre agent**, vient après votre site Web. Il vous faut un numéro pour terminer la configuration. Vous parlez à votre agent vers la fin de la configuration, sur **Rencontrez votre agent**.

<Steps>
  <Step title="Choisissez un numéro">
    Choisissez le pays de votre numéro, puis un numéro dans la liste. Pour voir les numéros d'une autre zone, entrez un indicatif régional et cliquez sur **Rechercher**.
  </Step>

  <Step title="Appelez votre numéro">
    Appelez le numéro depuis n'importe quel téléphone. Votre agent IA répond.
  </Step>
</Steps>

Si votre numéro a commencé un essai gratuit, LobbyStack affiche les forfaits à la fin de la configuration, après **Rencontrez votre agent**. Cliquez sur **Commencer l'essai gratuit de 14 jours** pour garder l'essai, sans carte bancaire, ou sur **S'abonner** sous Starter ou Pro pour payer dès maintenant. Vos 14 jours ont commencé quand vous avez obtenu le numéro.

Si LobbyStack ne peut pas vous offrir d'essai gratuit, l'étape du numéro affiche plutôt Starter, Pro et Enterprise. C'est le cas si vous avez déjà utilisé un essai, si un essai a déjà commencé depuis votre réseau au cours des 30 derniers jours, si LobbyStack ne peut pas vérifier votre réseau, si vous n'avez pas confirmé votre adresse courriel, ou dans un pays sans essai. Abonnez-vous, et LobbyStack vous ramène au choix du numéro. Si votre pays n'a pas de numéros, choisissez-le dans la liste **Pays** à côté des forfaits pour continuer sans numéro.

Si LobbyStack ne vend pas encore de numéros dans votre pays, choisissez **Autre pays** dans la liste **Pays**, puis votre pays dans la liste qui s'ouvre. Cliquez sur **M'écrire quand ils seront disponibles** pour être prévenu à l'arrivée des numéros, puis sur **Continuer sans numéro**. Vous continuez à tester votre agent avec des appels depuis le navigateur. Consultez [les pays où les numéros sont disponibles](/fr/getting-started/number-countries).

## Essai gratuit du numéro

Sans forfait payant, votre numéro est gratuit pendant 14 jours, sans carte bancaire. L'essai suit ces règles :

- Les numéros d'essai sont offerts aux États-Unis, au Canada et à Porto Rico.
- L'essai se termine à la fin du 14e jour, dans le fuseau horaire de votre entreprise. Le jour 1 est celui où vous obtenez le numéro.
- L'essai inclut les 30 minutes vocales du forfait Gratuit. Une fois ces minutes épuisées, LobbyStack renvoie les appels vers votre [numéro de transfert](/fr/agent/calls-and-booking#numéro-de-transfert-par-défaut) jusqu'à ce que vous passiez à un forfait payant.
- Si votre essai a commencé avec un numéro de mobile vérifié, votre agent transfère les appels de l'essai uniquement vers ce numéro. Sinon, les règles de votre numéro de transfert s'appliquent.
- Passez à Starter ou à Pro pendant l'essai pour garder le même numéro.
- Chaque entreprise et chaque compte n'a droit qu'à un seul essai.
- LobbyStack vous envoie un courriel le 10e jour, le 13e jour et le lendemain de la fin de l'essai.

Pendant l'essai, le bas de la barre latérale affiche **Essai gratuit · N j restants**, avec les jours qu'il vous reste. Cliquez sur **Voir les forfaits** pour vous abonner. La bannière en haut du tableau de bord n'apparaît que lorsque l'essai n'a plus de minutes ou se termine.

À la fin de l'essai, votre agent cesse de répondre aux appels sur ce numéro. Abonnez-vous à Starter ou à Pro pour garder le numéro, et votre agent répond de nouveau. LobbyStack libère le numéro environ un mois après que vous l'avez obtenu. Sans forfait, votre espace de travail passe au forfait Gratuit sans numéro. Vous gardez 30 minutes vocales pour les appels test dans le navigateur, et le clavardage sur votre site.

Si vous avez terminé la configuration sans numéro, ouvrez les **Canaux** de votre agent, cliquez sur **Obtenir un numéro**, puis sur **Choisir mon numéro** pour commencer l'essai. **Associez un numéro**, dans **Premiers pas** sur l'**Accueil**, offre la même chose. Seuls les propriétaires et les administrateurs peuvent choisir un numéro.

## Utiliser votre numéro d'entreprise actuel

Vos clients n'ont pas à apprendre un nouveau numéro. Renvoyez votre ligne d'entreprise actuelle vers votre numéro LobbyStack, et votre agent répond aux appels qui y arrivent. Vous choisissez de renvoyer seulement les appels manqués ou tous les appels.

<Card title="Renvoyer vos appels" icon="phone" href="/fr/getting-started/forward-calls">
  Trouvez le code ou les réglages de votre fournisseur, puis vérifiez que le renvoi fonctionne.
</Card>

## Votre numéro après la fin d'un forfait payant

Quand votre forfait payant prend fin, vous gardez votre numéro pendant 30 jours de plus, puis LobbyStack le libère. LobbyStack vous envoie un courriel quand vous annulez, puis un autre trois jours avant la libération. Abonnez-vous de nouveau avant la date de libération pour garder le numéro.

## Portabilité du numéro

Le moyen le plus rapide de garder votre numéro d'entreprise actuel est le [renvoi d'appel](/fr/getting-started/forward-calls) : les appelants composent le numéro qu'ils connaissent déjà, et les appels renvoyés arrivent à votre agent LobbyStack. Si vous avez plutôt besoin de transférer votre numéro chez nous (portabilité), communiquez avec l'équipe pour que nous étudiions la meilleure solution selon votre opérateur et votre région.
