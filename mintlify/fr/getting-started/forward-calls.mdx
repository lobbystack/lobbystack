Le renvoi d'appel envoie les appels de votre ligne d'entreprise actuelle vers votre numéro LobbyStack, et votre réceptionniste y répond. Vos clients continuent de composer le numéro qu'ils connaissent. Vous activez le renvoi auprès de votre fournisseur, depuis le téléphone que vos clients appellent.

Le tableau de bord affiche ces étapes avec votre numéro déjà inscrit. Pendant l'essai gratuit, cliquez sur **Configurer le renvoi** dans **Accueil**. Après votre abonnement, cliquez sur **Guide du renvoi d'appel** dans la page qui confirme votre forfait.

## Choisir les appels à renvoyer

| Option | Ce qui se passe |
| --- | --- |
| **Appels manqués** | Votre téléphone sonne d'abord. Si vous ne répondez pas, votre réceptionniste prend l'appel. |
| **Tous les appels** | Votre réceptionniste répond à chaque appel, et votre téléphone ne sonne pas. |

Les appels manqués couvrent trois cas : vous ne répondez pas, vous êtes déjà au téléphone, ou votre téléphone est éteint ou sans réseau. Certains fournisseurs gèrent les trois avec un seul code, d'autres utilisent un code par cas.

## Avant de commencer

- Votre numéro LobbyStack se trouve dans **Réglages** > **Numéro de téléphone**.
- Les codes de cette page utilisent le numéro d'exemple (555) 123-4567. Remplacez `5551234567` par les 10 chiffres de votre numéro LobbyStack.
- Certains fournisseurs veulent un 1 devant le numéro, et leurs codes affichent donc `15551234567`. Gardez le 1 et remplacez les 10 chiffres qui suivent.
- Les menus sont indiqués en anglais, comme dans le tableau de bord. Votre téléphone ou votre fournisseur peut les afficher en français.

## Activer le renvoi avec un code

<Steps>
  <Step title="Composez le code">
    Sur le téléphone que vos clients appellent, composez le code de votre fournisseur indiqué dans la colonne **Activer**. Certains codes se terminent sans numéro, comme `*72`. Pour ceux-là, la ligne vous demande le numéro après l'appel : entrez-le dans le format indiqué dans le tableau.
  </Step>
  <Step title="Appuyez sur Appeler">
    Une tonalité ou un message confirme que le renvoi est activé.
  </Step>
  <Step title="Composez les codes supplémentaires">
    Pour les appels manqués, certains fournisseurs séparent les cas en plusieurs codes. Composez le code **Occupé** pour renvoyer aussi les appels reçus pendant que vous êtes au téléphone. Composez le code **Injoignable** pour renvoyer aussi les appels quand votre téléphone est éteint ou sans réseau.
  </Step>
</Steps>

Pour désactiver le renvoi plus tard, composez les codes de la colonne **Désactiver**.

## Activer le renvoi dans les réglages

Certains fournisseurs et la plupart des systèmes téléphoniques d'entreprise utilisent un écran de réglages plutôt qu'un code.

<Steps>
  <Step title="Ouvrez les réglages">
    Ouvrez le menu indiqué dans la colonne **Activer**. Selon le fournisseur, il se trouve sur votre téléphone, dans l'application du fournisseur ou sur son site Web.
  </Step>
  <Step title="Indiquez le numéro de renvoi">
    Renvoyez les appels sans réponse, ou tous les appels, vers votre numéro LobbyStack, puis enregistrez.
  </Step>
</Steps>

Pour désactiver le renvoi plus tard, revenez au même menu.

## Tester le renvoi

Appelez votre numéro d'entreprise depuis un autre téléphone. Si vous renvoyez les appels manqués, laissez sonner. Votre réceptionniste devrait répondre.

## Si votre fournisseur n'est pas dans la liste

Demandez à votre fournisseur de renvoyer les appels sans réponse, ou tous vos appels, vers votre numéro LobbyStack.
