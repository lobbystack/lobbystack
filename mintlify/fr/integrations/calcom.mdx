Connectez Cal.com si votre équipe y prend déjà ses réservations. Votre agent IA réserve chaque rendez-vous comme une réservation Cal.com d'un type d'événement, et il compte chaque réservation du compte comme du temps occupé. Il n'offre donc pas les heures déjà réservées sur votre page de réservation Cal.com.

<Note>
  Ajoutez les services que les appelants peuvent demander avant de connecter Cal.com. LobbyStack compare leur durée avec le type d'événement que vous choisissez.
</Note>

## Ce que Cal.com reçoit

Pour chaque rendez-vous, Cal.com reçoit :

- **Nom et numéro de téléphone du participant** : ceux de l'appelant, pour que vous sachiez qui a réservé
- **Courriel du participant** : une adresse de remplacement propre au rendez-vous, pour que Cal.com n'écrive pas à l'appelant
- **Notes et métadonnées de réservation** : le nom, le numéro de téléphone et le vrai courriel de l'appelant, pour que vous puissiez le joindre

L'agent IA envoie lui-même la confirmation et les rappels à l'appelant. Cal.com continue d'envoyer ses notifications d'hôte à votre équipe.

## Connecter Cal.com

<Steps>
  <Step title="Ouvrir Intégrations">
    Dans le tableau de bord, ouvrez **Intégrations**.
  </Step>
  <Step title="Lancer la connexion Cal.com">
    Repérez **Cal.com** et cliquez sur **Connecter**.
  </Step>
  <Step title="Autoriser LobbyStack">
    Connectez-vous à Cal.com et approuvez les autorisations demandées.
  </Step>
  <Step title="Choisir un type d'événement">
    De retour dans le tableau de bord, choisissez un type d'événement sous **Type d'événement**. LobbyStack enregistre votre choix aussitôt.
  </Step>
</Steps>

LobbyStack commence à lire vos réservations Cal.com, et les calendriers que Cal.com vérifie pour les conflits, en quelques secondes.

## Configurer le type d'événement dans Cal.com

Une fois le type d'événement choisi, la boîte de dialogue liste ce qu'il faut corriger dans Cal.com :

- **Durées** : le type d'événement doit offrir chaque durée de vos services. Ajoutez les durées manquantes dans les réglages de durée du type d'événement, sinon Cal.com réserve sa durée par défaut.
- **Workflow SMS** : désactivez tout workflow SMS du type d'événement. Sinon, les appelants reçoivent des textos de Cal.com et de votre agent IA.
- **Lieu** : ajoutez **Numéro de téléphone du participant** comme lieu. Sinon, les réservations portent un lien vidéo et votre équipe doit chercher le numéro de l'appelant dans les notes de réservation.
- **Horaire** : les disponibilités du type d'événement doivent couvrir vos heures d'ouverture. Cal.com refuse les réservations hors de son horaire, et le tableau de bord vous alerte quand une réservation ne se synchronise pas.

## Utiliser Cal.com avec Google Calendar

Vous pouvez connecter Google Calendar et Cal.com en même temps. Le temps occupé dans les deux bloque les réservations, et les nouveaux rendez-vous vont dans Cal.com dès que vous choisissez son type d'événement. Cal.com les reçoit parce que sa page de réservation prend des réservations de son côté, et une réservation Cal.com y bloque l'heure aussitôt. Le calendrier propre d'un membre de l'équipe passe quand même en premier pour ses rendez-vous.

## Changer de type d'événement

1. Ouvrez **Intégrations**.
2. Cliquez sur la carte Cal.com.
3. Choisissez un autre type d'événement.

Les nouveaux rendez-vous utilisent le nouveau type d'événement. Les rendez-vous à venir y passent à la synchronisation suivante.

## Quand une réservation change dans Cal.com

Si vous annulez une réservation dans Cal.com, LobbyStack annule le rendez-vous et vous envoie une alerte. Les appelants qui ont accepté les textos reçoivent un texto d'annulation.

Si vous déplacez une réservation dans Cal.com, LobbyStack déplace le rendez-vous et son rappel, puis vous alerte pour que vous puissiez annoncer la nouvelle heure à l'appelant. LobbyStack n'envoie pas de texto à l'appelant pour ce changement. Si le membre du personnel a déjà un rendez-vous à la nouvelle heure, LobbyStack garde l'heure d'origine et vous alerte pour que vous régliez le conflit.

## Reconnecter ou déconnecter

Si Cal.com n'accepte plus la connexion, la carte indique qu'une reconnexion est requise. Ouvrez la carte Cal.com et cliquez sur **Reconnecter**.

Pour retirer l'intégration, ouvrez la carte Cal.com et cliquez sur **Déconnecter**. LobbyStack annule les réservations à venir que votre agent IA a faites dans Cal.com, et votre page de réservation affiche de nouveau ces heures comme libres. Si Google Calendar est connecté aussi, ces rendez-vous y passent. Les réservations passées restent dans Cal.com.
