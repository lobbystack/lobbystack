Ce tutoriel suit le parcours de configuration du tableau de bord LobbyStack, de la création du compte jusqu'au premier test de votre agent.

<Note>
  Aucune carte bancaire n'est requise. Sans forfait payant, votre numéro de téléphone est gratuit pendant 14 jours. Les forfaits Starter et Pro incluent un numéro. Les limites d'utilisation de la version hébergée s'affichent dans **Réglages** > **Utilisation** une fois connecté. [Vérifiez où les numéros sont disponibles](/fr/getting-started/number-countries).
</Note>

<NoCodePrompt />

## Avant de commencer

Il vous faut :

- Une adresse courriel et un mot de passe.
- Un téléphone mobile capable de recevoir des SMS, si LobbyStack vous demande d'en vérifier un avant votre numéro d'essai gratuit. LobbyStack ne peut pas vérifier les numéros Internet (VoIP).
- L'URL d'un site Web public, si vous voulez que LobbyStack importe les connaissances de votre site pendant la configuration.

## Étapes de configuration

<Steps>
  <Step title="Créez votre compte">
    Ouvrez la page d'inscription de LobbyStack, entrez votre adresse courriel et votre mot de passe, puis envoyez le formulaire.

    LobbyStack ouvre la configuration après l'inscription.
  </Step>

  <Step title="Nommez votre entreprise">
    Entrez le nom d'entreprise que LobbyStack doit afficher dans le tableau de bord et dans les informations visibles par vos clients.
  </Step>

  <Step title="Importez votre site Web">
    Entrez l'URL d'un site Web public pour lancer une importation en arrière-plan, ou choisissez **Je n'ai pas de site web**.

    L'importation du site Web parcourt les pages publiques comme les services, la page À propos, la FAQ, les heures d'ouverture et la page de contact. Les pages privées, les URL de réseau local et les pages qui exigent une connexion ne sont pas importées.

    LobbyStack affiche la progression de l'importation pendant qu'elle tourne. Cliquez sur **Ne pas attendre** pour continuer : l'importation se poursuit. Elle règle aussi la langue des appelants de votre agent d'après votre site. Sans site Web, vous choisissez la langue vous-même.
  </Step>

  <Step title="Choisissez votre numéro">
    Choisissez le pays de votre numéro, puis un numéro dans la liste. Sans forfait payant, il est gratuit pendant 14 jours. Consultez [le fonctionnement de l'essai gratuit](/fr/getting-started/claim-your-number#essai-gratuit-du-numéro).

    LobbyStack vous demande de vérifier un numéro de mobile d'abord lorsqu'il ne peut pas confirmer le réseau depuis lequel vous faites la configuration, ou lorsqu'un essai gratuit a déjà commencé depuis ce réseau au cours des 30 derniers jours. Pendant l'essai, les appels sont transférés uniquement vers ce mobile.

    Si LobbyStack ne vend pas encore de numéros dans votre pays, demandez à être prévenu par courriel quand ce sera le cas, et continuez à tester votre agent dans votre navigateur.
  </Step>

  <Step title="Indiquez votre objectif">
    Choisissez ce que votre agent doit faire en premier, puis dites comment vous avez connu LobbyStack. Vous pouvez passer ces deux questions.
  </Step>

  <Step title="Rencontrez votre agent">
    Testez votre agent dans votre navigateur par un appel ou un clavardage, ou appelez votre numéro si vous en avez choisi un. Autorisez l'accès au micro quand votre navigateur le demande.

    Sur le même écran, changez le nom, la voix, le message d'accueil et la langue des appelants de votre agent. Après votre premier test réussi, LobbyStack affiche les forfaits une fois. Cliquez sur **Pas maintenant** pour continuer vos tests.

    Cliquez sur **Aller au tableau de bord** quand vous êtes prêt.
  </Step>

  <Step title="Renvoyez votre ligne d'entreprise">
    Pour garder le numéro que vos clients composent déjà, [renvoyez-le vers votre numéro LobbyStack](/fr/getting-started/forward-calls).
  </Step>

  <Step title="Ouvrez le tableau de bord">
    Avant que de vrais appelants joignent votre agent, ouvrez-le depuis **Agents** et vérifiez sa page **Général**, ses instructions et ses règles. Vérifiez ensuite **Détails de l'entreprise**, **Connaissances**, **Services** et **Employés** dans **Réglages**. Pour ajouter des documents, ouvrez **Ajoutez d'autres sources** dans **Premiers pas**, sur l'**Accueil**.
  </Step>
</Steps>
