Ce tutoriel suit le parcours de configuration du tableau de bord LobbyStack, de la création du compte jusqu'à votre premier appel test.

<Note>
  Aucune carte de crédit n'est requise pour créer un compte. Avec le forfait Gratuit, vous pouvez essayer LobbyStack grâce aux appels test du tableau de bord. Les forfaits Starter et Pro incluent un numéro d'entreprise dédié. Les limites d'utilisation de la version hébergée s'affichent dans **Réglages** une fois connecté.
</Note>

## Avant de commencer

Il vous faut :

- Une adresse courriel et un mot de passe.
- Un numéro de mobile capable de recevoir un code de vérification par SMS.
- L'URL d'un site Web public, si vous voulez que LobbyStack importe les connaissances de votre site pendant la configuration.

## Étapes de configuration

<Steps>
  <Step title="Créez votre compte">
    Ouvrez la page d'inscription de LobbyStack, entrez votre adresse courriel et votre mot de passe, puis envoyez le formulaire.

    LobbyStack ouvre la configuration après l'inscription.
  </Step>

  <Step title="Nommez votre entreprise">
    Entrez le nom d'entreprise que LobbyStack doit afficher dans le tableau de bord et dans les informations visibles par vos clients.
  </Step>

  <Step title="Importez votre site Web">
    Entrez l'URL d'un site Web public pour lancer une importation en arrière-plan, ou choisissez **Ignorer pour l'instant**.

    L'importation du site Web parcourt les pages publiques comme les services, la page À propos, la FAQ, les heures d'ouverture et la page de contact. Les pages privées, les URL de réseau local et les pages qui exigent une connexion ne sont pas importées.
  </Step>

  <Step title="Ajoutez des documents de connaissances">
    Téléversez des documents d'entreprise pris en charge, ajoutez du texte ou passez l'étape. Vous pourrez gérer ces sources plus tard dans **Agent** > **Connaissances**.
  </Step>

  <Step title="Rédigez le message d'accueil">
    Écrivez la phrase d'ouverture que les appelants entendront. Vous pourrez modifier la voix et le comportement de transfert plus tard dans **Agent** > **Paramètres IA**.
  </Step>

  <Step title="Vérifiez votre numéro de mobile">
    Entrez un numéro de mobile au format international et demandez un code de vérification. Entrez le code à six chiffres reçu par SMS.

    LobbyStack utilise le numéro vérifié pour la sécurité du compte, les alertes et les suggestions de numéros locaux.
  </Step>

  <Step title="Choisissez un forfait">
    Sélectionnez Gratuit, Starter ou Pro. Le forfait Gratuit inclut les appels test du tableau de bord, sans numéro public dédié. Les forfaits Starter et Pro incluent un numéro d'entreprise dédié.
  </Step>

  <Step title="Obtenez un numéro de téléphone avec un forfait payant">
    Avec Starter ou Pro, vérifiez le numéro d'entreprise suggéré ou cliquez sur **Choisir un autre numéro** pour chercher par ville, par indicatif régional ou parmi les numéros sans frais.

    Cliquez sur **Continuer** pour obtenir le numéro sélectionné. Les appels vers ce numéro sont dirigés vers votre réceptionniste IA. Le forfait Gratuit passe cette étape ; vous pourrez changer de forfait plus tard dans **Réglages**.
  </Step>

  <Step title="Terminez la configuration">
    Indiquez comment vous avez connu LobbyStack, puis ouvrez le tableau de bord. Vérifiez **Paramètres IA**, **Connaissances**, **Services** et **Règles** avant d'envoyer de vrais appels vers le numéro.
  </Step>
</Steps>
