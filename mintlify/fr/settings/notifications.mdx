La page **Réglages** > **Notifications** contrôle les alertes de l'entreprise active. Vous pouvez activer le courriel, le SMS ou les deux pour les événements qui demandent l'attention de votre équipe.

## Choisir les canaux de notification

Activez les canaux que votre équipe surveille :

- **Courriel** : envoie les alertes à l'adresse courriel du compte
- **SMS** : envoie les alertes urgentes au numéro de téléphone vérifié de l'opérateur

Les alertes SMS demandent un consentement explicite. Consultez [Alertes SMS et consentement](/fr/integrations/sms) avant de les activer.

## Choisir les événements d'alerte

LobbyStack peut avertir votre équipe dans les cas suivants :

- Un message vocal qui demande un rappel
- Un nouveau texto envoyé à votre numéro d'entreprise
- Un nouveau clavardage sur le site Web qui demande votre attention
- L'échec d'une notification SMS envoyée à un client
- Un problème de synchronisation du calendrier
- L'échec d'un transfert d'appel en direct

Activez les alertes qui demandent l'intervention d'une personne. Laissez désactivés les événements de livraison courants si votre équipe n'en a pas besoin.

## Appliquer les réglages

LobbyStack enregistre chaque modification de canal ou d'événement dès que vous la faites. Vérifiez que le courriel du compte et le numéro de téléphone vérifié appartiennent à une personne responsable de l'espace de travail.
