La page **Connaissances** vous permet d'ajouter les informations que l'agent utilise pour répondre aux appelants. Servez-vous-en pour les faits simples à retrouver : heures d'ouverture, adresse, stationnement, notes sur les prix, descriptions des services, politiques, documents à fournir et FAQ.

LobbyStack prend en charge trois sources de connaissances : les entrées de texte, les documents téléversés et les importations de sites Web publics.

<Note>
  Les forfaits hébergés incluent 1 Mo de texte de connaissances avec Gratuit, 5 Mo avec Starter et 20 Mo avec Pro, soit environ 400, 2 000 et 8 000 pages. La limite compte le texte que LobbyStack extrait de vos documents et sites web, pas la taille des fichiers. Chaque document téléversé peut faire jusqu'à 10 Mo.
</Note>

## Entrées de texte

Les entrées de texte conviennent le mieux aux faits courts qui font autorité.

| Titre de l'entrée | Bon contenu |
| --- | --- |
| Horaire des jours fériés | Nous sommes fermés les jours fériés. Si un appelant pose une question sur un jour férié précis, prenez un message pour que l'équipe confirme. |
| Stationnement | Les clients peuvent utiliser le stationnement derrière l'immeuble. Le stationnement sur rue est aussi permis sur la rue Pine après 18 h. |
| Politique d'annulation | Veuillez appeler au moins 24 heures avant le rendez-vous pour l'annuler ou le déplacer. |
| Accueil des nouveaux clients | Les nouveaux clients doivent apporter une pièce d'identité, leurs renseignements d'assurance s'il y a lieu, ainsi que toute lettre de recommandation ou note de service en leur possession. |

<Steps>
  <Step title="Ouvrez Connaissances">
    Allez dans **Entreprise** > **Connaissances**.
  </Step>
  <Step title="Choisissez Texte">
    Cliquez sur **Ajouter** et choisissez **Texte**.
  </Step>
  <Step title="Ajoutez un titre et un contenu">
    Utilisez un titre court et rédigez la réponse complète dans le champ de contenu.
  </Step>
  <Step title="Ajoutez">
    Cliquez sur **Ajouter**. L'entrée apparaît dans le tableau.
  </Step>
</Steps>

## Documents téléversés

Téléversez des fichiers PDF, des documents Word, des fichiers texte et des fichiers Markdown qui contiennent des informations utiles pour les appelants.

| Limite | Valeur |
| --- | --- |
| Types pris en charge | PDF, DOCX, TXT, Markdown |
| Taille maximale | 10 Mo par fichier |

LobbyStack traite les documents téléversés avant qu'ils soient prêts. Le tableau affiche des statuts comme en file d'attente, en indexation, prêt ou erreur.

<Note>
  Ne téléversez que des documents prêts à être communiqués aux appelants. Utilisez du contenu à jour et approuvé pour que l'agent donne les mêmes informations que votre équipe.
</Note>

## Importation du site Web

L'importation du site Web parcourt une URL publique et ajoute les pages utiles à la base de connaissances. Elle vise les pages publiques comme les services, la page À propos, la FAQ, les heures d'ouverture, les emplacements, les menus, les prix et la page de contact.

L'importation du site Web se concentre sur les pages publiques destinées aux appelants et ignore :

- Les URL localhost, de réseau local ou d'adresse IP directe.
- Les pages qui exigent une connexion.
- Les pages peu utiles comme le paiement, le panier, le compte, la recherche, la confidentialité et les conditions d'utilisation.
- Les fichiers statiques comme les images, les PDF, les feuilles de calcul, les fichiers ZIP, les scripts et les feuilles de style.

<Steps>
  <Step title="Ouvrez la fenêtre d'importation du site Web">
    Allez dans **Entreprise** > **Connaissances**, cliquez sur **Ajouter** et choisissez **Site web**.
  </Step>
  <Step title="Entrez une URL publique">
    Collez l'URL de la page d'accueil ou de la section que LobbyStack doit parcourir.
  </Step>
  <Step title="Lancez l'importation">
    Cliquez sur **Importer**. Le site Web apparaît sur une ligne, et son nombre de pages augmente au fur et à mesure du traitement.
  </Step>
</Steps>

## Répondre aux questions sans réponse

Quand votre agent cherche une réponse dans vos connaissances sans rien trouver, LobbyStack enregistre la question sous **Questions sans réponse** dans la page Connaissances. Cela vaut pour les appels téléphoniques, les appels depuis le navigateur, les clavardages sur le site Web et les messages Instagram. Vos propres appels test comptent aussi.

La liste affiche jusqu'à 50 questions, des plus posées aux moins posées, avec le nombre de fois où on les a posées et la date de la dernière fois. Chaque question apparaît telle que votre agent l'a cherchée, jusqu'à 300 caractères, donc sa formulation peut différer de celle de l'appelant.

Une question posée de nouveau avec d'autres majuscules ou une autre ponctuation compte sur la même ligne. Une question reformulée a sa propre ligne.

<Steps>
  <Step title="Ouvrez les questions sans réponse">
    Allez dans **Entreprise** > **Connaissances** et faites défiler jusqu'à **Questions sans réponse**. Quand des questions attendent, les propriétaires et les administrateurs ont aussi un lien sous **Action requise** dans l'[Accueil](/fr/dashboard/home).
  </Step>
  <Step title="Écrivez la réponse">
    Cliquez sur **Répondre**, écrivez ce que l'agent doit dire en 5 000 caractères au plus et cliquez sur **Enregistrer la réponse**. LobbyStack ajoute au tableau Connaissances une entrée de texte titrée avec la question. Les nouveaux appels et les nouvelles conversations l'utilisent peu après l'enregistrement, et vous pouvez la modifier comme toute autre entrée.
  </Step>
  <Step title="Ignorez celles auxquelles vous ne répondrez pas">
    Cliquez sur **Ignorer** pour retirer une question de la liste.
  </Step>
</Steps>

### Ce qui se passe quand quelqu'un la pose de nouveau

| Question | Si quelqu'un la pose de nouveau |
| --- | --- |
| Avec une réponse | Votre agent utilise votre réponse. Si sa recherche ne trouve toujours rien, la question revient dans la liste comme une nouvelle question, et son compteur repart à 1. |
| Ignorée | La question reste hors de la liste, même si d'autres personnes la posent. Elle revient comme une nouvelle question seulement si quelqu'un la pose après que LobbyStack l'a supprimée. |

Vous ne pouvez pas rétablir une question ignorée depuis le tableau de bord. Pour y répondre plus tard, ajoutez vous-même une [entrée de texte](#entrées-de-texte).

### Qui peut répondre aux questions

Les propriétaires et les administrateurs peuvent répondre aux questions et les ignorer. Les lecteurs peuvent consulter la liste, mais ils n'ont ni les boutons **Répondre** et **Ignorer**, ni le lien dans l'Accueil. Si votre entreprise a l'accès **Activité seulement** par l'intermédiaire d'un partenaire, votre équipe ne voit pas la page Connaissances.

### Combien de temps LobbyStack conserve les questions

LobbyStack supprime une question 30 jours après la dernière fois qu'on l'a posée avec le forfait Free, ou 365 jours avec Starter et Pro. Chaque nouvelle demande relance cette période, même pour une question ignorée. Une entrée de texte enregistrée comme réponse reste dans vos connaissances jusqu'à ce que vous la supprimiez.

## Gérer les sources

Le tableau Connaissances montre une ligne par source. Un site Web tient sur une ligne avec son nombre de pages, et chaque fichier et chaque entrée de texte a sa propre ligne. Depuis le tableau, vous pouvez :

- Ouvrir la ligne d'un fichier pour lire le texte que LobbyStack en a extrait.
- Ouvrir la ligne d'une entrée de texte pour la modifier.
- Désactiver une source sans la supprimer, puis la réactiver.
- Supprimer une source définitivement. Supprimer un site Web supprime toutes ses pages et arrête une importation qui en ajoute encore.

### Gérer les pages d'un site Web

Cliquez sur la ligne d'un site Web pour ouvrir ses pages. Chaque page a son propre interrupteur : vous pouvez désactiver une page dont l'agent ne doit pas se servir et garder les autres. Vous pouvez aussi retirer des pages, sauf l'adresse que vous avez importée, et cliquer sur **Réimporter** pour relire le site. Si vous désactivez puis réactivez tout le site, les pages que vous aviez désactivées le restent.

### Agir sur plusieurs sources à la fois

<Steps>
  <Step title="Activez la sélection">
    Cliquez sur **Sélectionner** au-dessus du tableau. Une case à cocher apparaît sur chaque ligne.
  </Step>
  <Step title="Choisissez les lignes">
    Cochez les lignes voulues, ou la case de l'en-tête pour toutes les choisir.
  </Step>
  <Step title="Choisissez une action">
    Cliquez sur **Supprimer**, **Désactiver**, **Activer** ou, pour les sites Web, **Réimporter**. Cliquez sur **Annuler** ou appuyez sur Échap pour sortir sans rien changer.
  </Step>
</Steps>

## Donner à un agent ses propres connaissances

Chaque agent répond à partir des sources de cette page. Quand un agent a besoin d'autres renseignements, par exemple une ligne du soir avec son propre code de porte, ouvrez sa page **Connaissances spécifiques** : allez dans **Agents**, choisissez l'agent et cliquez sur **Connaissances spécifiques**.

La page contient deux tableaux :

- **Cet agent seulement** : les sources que vous ajoutez ici avec **Ajouter**. Les sites Web, fichiers et textes fonctionnent comme sur la page Connaissances, et aucun autre agent ne s'en sert.
- **Partagées avec tous les agents** : les sources de la page Connaissances. Chacune a un interrupteur qui la désactive pour cet agent seulement. Un site Web partagé ouvre ses pages, où vous pouvez désactiver une page pour cet agent.

Les nouvelles sources partagées sont activées pour chaque agent. Désactiver une source pour un agent ne change rien pour les autres. Une source désactivée sur la page Connaissances l'est pour tous les agents, et son interrupteur reste désactivé sur la page d'un agent.

Un site Web peut être dans les connaissances partagées ou dans celles d'un agent, pas les deux. Pour qu'un agent n'utilise pas un site Web partagé, désactivez-le sur la page de cet agent.

Les réponses aux [questions sans réponse](#répondre-aux-questions-sans-réponse) vont toujours dans les connaissances partagées. Le résumé de votre entreprise et vos heures d'ouverture viennent seulement des connaissances partagées. Quand vous retirez un agent, LobbyStack supprime les connaissances que seul cet agent utilisait.

<Tip>
  Mieux vaut un petit ensemble d'entrées exactes qu'une grande bibliothèque de contenu périmé. Pour les appelants, l'exactitude compte plus que le volume.
</Tip>
