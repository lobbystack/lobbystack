**Entreprise** > **Détails** contient ce qui est vrai de l'entreprise elle-même : chaque agent de l'espace de travail donne donc les mêmes réponses. Cliquez sur **Entreprise** dans la barre latérale, puis sur **Détails**.

## Résumé de l'entreprise

Le résumé de l'entreprise est ce que votre agent dit aux appelants qui demandent ce que fait ou offre l'entreprise. Il le lit avant chaque appel.

Vous n'avez pas à le rédiger. Quand vous ajoutez votre site Web ou vos documents dans les [Connaissances](/fr/settings/knowledge), l'IA en rédige un résumé de deux à quatre phrases, dans votre langue client par défaut. Elle le réécrit quelques minutes après un changement de vos connaissances, et seulement si le contenu a changé.

Pour rédiger le vôtre, cliquez sur **Modifier** à côté de **Résumé de l'entreprise**, changez le texte et cliquez sur **Enregistrer**. L'IA ne modifie jamais un résumé que vous avez rédigé.

Pour revenir à un résumé de l'IA, cliquez sur **Modifier**, puis sur **Réécrire avec l'IA**. L'IA réécrit le résumé à partir de vos connaissances et vous indique quand c'est fait. Si vos connaissances ne disent pas encore ce que fait l'entreprise, le résumé reste tel quel.

## Heures d'ouverture

Vos agents réservent des rendez-vous seulement pendant vos heures d'ouverture. Si la réservation instantanée est activée et qu'aucune heure n'est définie, un agent ne peut proposer aucun créneau : il prend la demande de l'appelant en message pour votre équipe. Les réglages de rendez-vous de l'agent affichent un avertissement tant que vous n'avez pas ajouté vos heures.

Vous n'avez pas à les saisir. Quand votre site Web ou vos documents indiquent vos heures, l'IA remplit **Heures d'ouverture** quelques minutes après un changement de vos connaissances. Elle lit les heures dans n'importe quelle langue et enregistre une pause du midi comme deux plages le même jour. L'IA utilise seulement les heures que vos sources indiquent, et une note au-dessus des heures vous signale qu'elle les a remplies. Vérifiez-les.

Pour définir les heures vous-même, activez ou désactivez chaque jour, saisissez ses heures d'ouverture et de fermeture, puis cliquez sur **Enregistrer les heures**. Cliquez sur **Ajouter des heures** pour ajouter une deuxième plage autour d'une pause. L'IA ne modifie jamais les heures que vous avez enregistrées ici ou par l'API.

Pour les jours fériés et les autres périodes où vous êtes fermé, cliquez sur **Ajouter une fermeture** et indiquez quand vous fermez et rouvrez. Utilisez le fuseau horaire de votre entreprise, puis cliquez sur **Enregistrer les heures**. Vos agents ne réservent aucun rendez-vous pendant une fermeture. Ils disent aux appelants que l'entreprise est fermée à ce moment-là et leur proposent un autre jour.

## Langue client par défaut

Les appels commencent dans votre **Langue client par défaut** : votre agent accueille les appelants dans cette langue. Quand un appelant demande une autre langue ou en parle une autre, votre agent passe à cette langue. Il peut converser avec les appelants dans plus de 70 langues.

Le réglage **Langue client par défaut** prend en charge :

| Option | Valeur |
| --- | --- |
| Anglais | `en` |
| Français | `fr` |
| Espagnol | `es` |
| Serbe (alphabet latin) | `sr` |
| Allemand | `de` |
| Portugais (Brésil) | `pt` |
| Italien | `it` |
| Néerlandais | `nl` |
| Polonais | `pl` |
| Turc | `tr` |
| Vietnamien | `vi` |
| Tagalog | `tl` |
| Suédois | `sv` |
| Russe | `ru` |
| Ukrainien | `uk` |

Choisissez la langue que parlent la plupart de vos appelants. Un agent dont vous n'avez pas modifié le message d'accueil passe au message d'accueil par défaut de la nouvelle langue.

<Note>
  Rédigez votre message d'accueil, vos connaissances, vos services et vos règles dans les langues que vos appelants utilisent le plus.
</Note>

## Langue de l'équipe

La **Langue de l'équipe** est la langue dans laquelle vos agents rédigent les messages, les notes et les demandes pour votre équipe. Les appelants entendent toujours leur propre langue. Choisissez **Identique à la langue des clients** pour suivre la langue client par défaut.

## Fuseau horaire de l'entreprise

Vos agents utilisent le **Fuseau horaire de l'entreprise** pour vos heures d'ouverture et pour les créneaux qu'ils proposent aux clients.

## Devise

Choisissez dans **Devise** la devise de vos [prix de services](/fr/settings/services#prix). Vos agents annoncent les prix dans cette devise. Si vous changez de devise plus tard, les montants que vous avez saisis restent les mêmes.
