L'URL du serveur est `https://app.lobbystack.com/api/mcp`. Si vous auto-hébergez LobbyStack, remplacez `app.lobbystack.com` par votre propre domaine. ChatGPT s'y connecte depuis Internet : un LobbyStack auto-hébergé a donc besoin d'une adresse HTTPS publique.

Consultez [Serveur MCP](/fr/ai/mcp) pour savoir quels outils chaque autorisation débloque.

## ChatGPT

ChatGPT connecte les serveurs MCP personnalisés depuis sa page **Plugins**, sur le Web. Avec les forfaits Business, Enterprise et Edu, ChatGPT peut utiliser tous les outils de LobbyStack, y compris ceux qui modifient des données. Avec Pro, il ne peut utiliser que les outils qui lisent des données. Dans un espace de travail Business, seuls les administrateurs et les propriétaires peuvent ajouter un serveur personnalisé. Avec Enterprise et Edu, les administrateurs peuvent accorder cette autorisation à d'autres membres.

<Steps>
  <Step title="Ajouter le serveur">
    Dans ChatGPT, allez dans **Plugins**, cliquez sur **+**, puis sur **Add custom MCP server**. Nommez-le `LobbyStack` et collez l'URL du serveur sous **Connection**. Vous n'avez pas besoin d'activer le mode développeur avant.
  </Step>
  <Step title="Choisir OAuth">
    Choisissez **OAuth** pour l'authentification et laissez vides les champs d'identifiant et de secret client : ChatGPT s'enregistre lui-même auprès de LobbyStack. Lisez l'avertissement sur les risques, cochez **I understand and want to continue** et cliquez sur **Create as a plugin**.
  </Step>
  <Step title="Se connecter et choisir l'accès">
    ChatGPT ouvre LobbyStack. Connectez-vous, choisissez l'entreprise, décochez ce que ChatGPT ne doit pas faire et cliquez sur **Autoriser l'accès**.
  </Step>
  <Step title="Installer le plugin">
    Vérifiez les outils trouvés par ChatGPT, puis installez le plugin. Dans une nouvelle conversation, tapez `@` et sélectionnez LobbyStack.
  </Step>
</Steps>

Pour déconnecter ChatGPT, allez dans **Réglages** > **Applications connectées** dans LobbyStack et cliquez sur **Déconnecter** à côté de ChatGPT.

## API Responses d'OpenAI

L'API Responses appelle les serveurs MCP distants pour vous. Passez une clé API dans `headers` :

```bash
curl https://api.openai.com/v1/responses \
  -H "Authorization: Bearer $OPENAI_API_KEY" \
  -H "content-type: application/json" \
  -d '{
    "model": "gpt-6-luna",
    "tools": [{
      "type": "mcp",
      "server_label": "lobbystack",
      "server_url": "https://app.lobbystack.com/api/mcp",
      "headers": { "Authorization": "Bearer '"$LOBBYSTACK_API_KEY"'" },
      "require_approval": "always"
    }],
    "input": "Who called yesterday and asked for a callback?"
  }'
```

`require_approval: "always"` arrête l'API avant chaque appel d'outil pour que votre code puisse le confirmer. N'assouplissez ce réglage que pour les clés qui ont seulement des portées de lecture.

## Codex

L'application de bureau ChatGPT, la CLI Codex et l'extension Codex pour IDE partagent la même configuration MCP : vous n'ajoutez LobbyStack qu'une fois. Ajoutez le serveur, puis connectez-vous :

```bash
codex mcp add lobbystack --url https://app.lobbystack.com/api/mcp
codex mcp login lobbystack
```

`codex mcp login` ouvre LobbyStack dans votre navigateur. Connectez-vous, choisissez l'entreprise, décochez ce que Codex ne doit pas faire et cliquez sur **Autoriser l'accès**. Codex s'enregistre lui-même auprès de LobbyStack : vous n'avez besoin ni d'identifiant ni de secret client. Demandez ensuite à Codex d'appeler `get_business` pour vérifier la connexion.

### Codex avec une clé API

Pour utiliser plutôt une clé API, ajoutez LobbyStack à `~/.codex/config.toml`. Codex lit la clé dans la variable d'environnement que vous indiquez :

```toml ~/.codex/config.toml
[mcp_servers.lobbystack]
url = "https://app.lobbystack.com/api/mcp"
bearer_token_env_var = "LOBBYSTACK_API_KEY"
```

Exportez `LOBBYSTACK_API_KEY` dans votre terminal avant de lancer Codex.
