Tout client MCP compatible avec Streamable HTTP peut se connecter. Les clients compatibles avec OAuth pour MCP se connectent seuls avec LobbyStack ; les autres ont besoin d'une clé API dans un en-tête.

| Paramètre | Valeur |
| --- | --- |
| URL | `https://app.lobbystack.com/api/mcp` |
| Transport | Streamable HTTP (parfois appelé `http`) |
| Authentification | OAuth, ou l'en-tête `Authorization: Bearer <API key>` |

Le serveur est sans état. Il prend en charge la révision 2026-07-28 du protocole et revient à Streamable HTTP pour les clients de 2025. Il ne prend pas en charge l'ancien transport HTTP+SSE : les clients qui ne proposent que SSE ne peuvent pas se connecter.

## Cursor

Ajoutez LobbyStack à `~/.cursor/mcp.json` pour l'utiliser dans tous vos projets, ou à `.cursor/mcp.json` dans un seul projet :

```json mcp.json
{
  "mcpServers": {
    "lobbystack": {
      "url": "https://app.lobbystack.com/api/mcp"
    }
  }
}
```

Cursor se connecte avec OAuth. Ouvrez **Customize** dans la barre latérale de Cursor, repérez `lobbystack` parmi les serveurs MCP et connectez-le. Cursor ouvre LobbyStack dans votre navigateur : connectez-vous, choisissez l'entreprise, décochez ce que Cursor ne doit pas faire et cliquez sur **Autoriser l'accès**.

Si le serveur ne se connecte pas, ouvrez le panneau Output (Cmd+Shift+U) et sélectionnez **MCP Logs**.

### Cursor avec une clé API

Pour utiliser plutôt une clé API, ajoutez un en-tête `Authorization`. Cursor lit la clé dans la variable d'environnement `LOBBYSTACK_API_KEY` :

```json mcp.json
{
  "mcpServers": {
    "lobbystack": {
      "url": "https://app.lobbystack.com/api/mcp",
      "headers": {
        "Authorization": "Bearer ${env:LOBBYSTACK_API_KEY}"
      }
    }
  }
}
```

## VS Code

VS Code ajoute les serveurs distants avec un parcours guidé. Ouvrez la palette de commandes (Cmd+Shift+P), exécutez **MCP: Add Server**, choisissez **HTTP (HTTP or Server-Sent Events)** et collez l'URL du serveur. Saisissez `lobbystack` comme identifiant du serveur, puis choisissez **Global** > **Copilot Global** pour utiliser LobbyStack dans tous vos espaces de travail. VS Code enregistre cette entrée dans `~/.copilot/mcp-config.json` :

```json ~/.copilot/mcp-config.json
{
  "mcpServers": {
    "lobbystack": {
      "type": "http",
      "url": "https://app.lobbystack.com/api/mcp"
    }
  }
}
```

Pour partager le serveur avec votre équipe, ajoutez la même entrée dans un fichier `.mcp.json` à la racine de votre espace de travail et versionnez-le.

Quand VS Code vous demande de vous connecter, LobbyStack s'ouvre dans votre navigateur. Connectez-vous, choisissez l'entreprise, décochez ce que VS Code ne doit pas faire et cliquez sur **Autoriser l'accès**. Si le serveur ne démarre pas, exécutez **MCP: List Servers**, sélectionnez `lobbystack` et choisissez **Show Output**.

### VS Code avec une clé API

Pour utiliser plutôt une clé API, ajoutez un en-tête `Authorization` qui lit la clé dans une variable d'environnement :

```json ~/.copilot/mcp-config.json
{
  "mcpServers": {
    "lobbystack": {
      "type": "http",
      "url": "https://app.lobbystack.com/api/mcp",
      "headers": { "Authorization": "Bearer ${LOBBYSTACK_API_KEY}" }
    }
  }
}
```

Définissez `LOBBYSTACK_API_KEY` dans l'environnement où VS Code s'exécute. Dans une fenêtre distante ou un conteneur de développement, définissez-la à cet endroit.

## Clients sans prise en charge des en-têtes

Si un client ne peut lancer que des serveurs locaux, exécutez [`mcp-remote`](https://www.npmjs.com/package/mcp-remote) comme serveur local et laissez-le ajouter l'en-tête. Le guide [Claude Desktop](/fr/ai/connect-claude#claude-desktop-avec-une-clé-api) montre la configuration.

## Tester avec MCP Inspector

L'outil en ligne de commande [MCP Inspector](https://github.com/modelcontextprotocol/inspector) se connecte sans modèle d'IA dans la boucle. Sans clé, il se connecte avec OAuth : il affiche un lien, vous l'ouvrez, vous vous connectez et autorisez l'accès, puis il liste les outils :

```bash
npx @modelcontextprotocol/inspector --cli https://app.lobbystack.com/api/mcp \
  --transport http --method tools/list
```

Avec une clé API :

```bash
npx @modelcontextprotocol/inspector --cli https://app.lobbystack.com/api/mcp \
  --transport http \
  --header "Authorization: Bearer $LOBBYSTACK_API_KEY" \
  --method tools/list
```

Appelez un outil de la même façon :

```bash
npx @modelcontextprotocol/inspector --cli https://app.lobbystack.com/api/mcp \
  --transport http \
  --header "Authorization: Bearer $LOBBYSTACK_API_KEY" \
  --method tools/call --tool-name get_business
```

## Créer votre propre client

Les SDK MCP officiels se connectent en quelques lignes. En TypeScript :

```ts
import { Client, StreamableHTTPClientTransport } from "@modelcontextprotocol/client";

const client = new Client({ name: "my-app", version: "1.0.0" });
await client.connect(new StreamableHTTPClientTransport(new URL("https://app.lobbystack.com/api/mcp"), {
  requestInit: { headers: { Authorization: `Bearer ${process.env.LOBBYSTACK_API_KEY}` } },
}));

const result = await client.callTool({ name: "list_messages", arguments: { status: "open" } });
console.log(result.structuredContent);
```

Si vous écrivez du code plutôt qu'un assistant, l'[API REST](/fr/api/overview) vous donne les mêmes données en HTTP simple.
