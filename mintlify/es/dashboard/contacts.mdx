La página **Contactos** muestra las personas vinculadas a sus llamadas, mensajes y citas. Los contactos se crean automáticamente a partir de las interacciones telefónicas y se actualizan con cada nueva actividad.

## Lista de contactos

Cada fila puede mostrar:

- El nombre del contacto o contacto desconocido.
- El número de teléfono y el correo electrónico, si están disponibles.
- El número de llamadas y mensajes.
- El número de citas.
- La hora de la última interacción.
- El estado de bloqueo.

Use la búsqueda para filtrar por nombre, número de teléfono o correo electrónico.

## Detalle del contacto

Abra un contacto para ver:

| Pestaña | Qué muestra |
| --- | --- |
| **Actividad** | Llamadas, mensajes SMS y actividad de citas en orden cronológico. |
| **Citas** | Servicio, fecha y hora, estado, canal y estado de sincronización con el calendario. |
| **Detalles** | Datos del contacto, estado de bloqueo, consentimiento para SMS y metadatos del sistema. |

## Bloquear contactos

Si bloquea un contacto, ya no se le pueden enviar respuestas por SMS y las nuevas llamadas entrantes de ese contacto se cuelgan de inmediato. Puede desbloquear el contacto más adelante desde el mismo menú.

## Consentimiento para SMS

La página de detalle del contacto indica si el contacto está suscrito a los SMS o se dio de baja, cuándo cambió el estado del consentimiento y el origen de ese cambio, si se conoce.

## Eliminar contactos

Los contactos con conversaciones o citas vinculadas se conservan para que el historial de actividad quede completo. Puede eliminar los contactos sin registros vinculados desde la página de detalle del contacto.

<Note>
  La eliminación de un contacto es permanente. Las conversaciones y citas vinculadas quedan protegidas para que su historial de actividad se mantenga intacto.
</Note>
