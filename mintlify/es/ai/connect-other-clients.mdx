Cualquier cliente MCP compatible con Streamable HTTP puede conectarse. Los clientes compatibles con MCP OAuth inician sesión con LobbyStack por sí solos; los demás necesitan una clave de API en un encabezado.

| Ajuste | Valor |
| --- | --- |
| URL | `https://app.lobbystack.com/api/mcp` |
| Transporte | Streamable HTTP (a veces aparece como `http`) |
| Autenticación | OAuth, o el encabezado `Authorization: Bearer <API key>` |

El servidor no guarda estado. Admite la revisión 2026-07-28 del protocolo y recurre a Streamable HTTP para los clientes de 2025. No admite el transporte HTTP+SSE antiguo, así que los clientes que solo ofrecen SSE no pueden conectarse.

## Cursor

Agregue LobbyStack a `~/.cursor/mcp.json` para usarlo en todos sus proyectos, o a `.cursor/mcp.json` en un solo proyecto:

```json mcp.json
{
  "mcpServers": {
    "lobbystack": {
      "url": "https://app.lobbystack.com/api/mcp"
    }
  }
}
```

Cursor inicia sesión con OAuth. Abra **Customize** en la barra lateral de Cursor, busque `lobbystack` entre los servidores MCP y conéctelo. Cursor abre LobbyStack en su navegador: inicie sesión, elija el negocio, desmarque lo que Cursor no deba hacer y haga clic en **Permitir acceso**.

Si el servidor no se conecta, abra el panel Output (Cmd+Shift+U) y seleccione **MCP Logs**.

### Cursor con una clave de API

Para usar una clave de API en su lugar, agregue un encabezado `Authorization`. Cursor lee la clave de la variable de entorno `LOBBYSTACK_API_KEY`:

```json mcp.json
{
  "mcpServers": {
    "lobbystack": {
      "url": "https://app.lobbystack.com/api/mcp",
      "headers": {
        "Authorization": "Bearer ${env:LOBBYSTACK_API_KEY}"
      }
    }
  }
}
```

## VS Code

VS Code agrega servidores remotos con un flujo guiado. Abra la paleta de comandos (Cmd+Shift+P), ejecute **MCP: Add Server**, elija **HTTP (HTTP or Server-Sent Events)** y pegue la URL del servidor. Escriba `lobbystack` como ID del servidor y luego elija **Global** > **Copilot Global** para usar LobbyStack en todos sus espacios de trabajo. VS Code guarda esta entrada en `~/.copilot/mcp-config.json`:

```json ~/.copilot/mcp-config.json
{
  "mcpServers": {
    "lobbystack": {
      "type": "http",
      "url": "https://app.lobbystack.com/api/mcp"
    }
  }
}
```

Para compartir el servidor con su equipo, agregue la misma entrada a un archivo `.mcp.json` en la raíz de su espacio de trabajo y súbalo al repositorio.

Cuando VS Code le pida iniciar sesión, LobbyStack se abre en su navegador. Inicie sesión, elija el negocio, desmarque lo que VS Code no deba hacer y haga clic en **Permitir acceso**. Si el servidor no se inicia, ejecute **MCP: List Servers**, seleccione `lobbystack` y elija **Show Output**.

### VS Code con una clave de API

Para usar una clave de API en su lugar, agregue un encabezado `Authorization` que lea la clave de una variable de entorno:

```json ~/.copilot/mcp-config.json
{
  "mcpServers": {
    "lobbystack": {
      "type": "http",
      "url": "https://app.lobbystack.com/api/mcp",
      "headers": { "Authorization": "Bearer ${LOBBYSTACK_API_KEY}" }
    }
  }
}
```

Defina `LOBBYSTACK_API_KEY` en el entorno donde se ejecuta VS Code. En una ventana remota o un contenedor de desarrollo, defínala ahí.

## Clientes sin compatibilidad con encabezados

Si un cliente solo puede iniciar servidores locales, ejecute [`mcp-remote`](https://www.npmjs.com/package/mcp-remote) como servidor local y deje que agregue el encabezado. La guía de [Claude Desktop](/es/ai/connect-claude#claude-desktop-con-una-clave-de-api) muestra la configuración.

## Pruebe con el MCP Inspector

La CLI del [MCP Inspector](https://github.com/modelcontextprotocol/inspector) se conecta sin un modelo de IA de por medio. Sin clave, inicia sesión con OAuth: muestra un enlace, usted lo abre, inicia sesión y permite el acceso, y la CLI muestra la lista de herramientas:

```bash
npx @modelcontextprotocol/inspector --cli https://app.lobbystack.com/api/mcp \
  --transport http --method tools/list
```

Con una clave de API:

```bash
npx @modelcontextprotocol/inspector --cli https://app.lobbystack.com/api/mcp \
  --transport http \
  --header "Authorization: Bearer $LOBBYSTACK_API_KEY" \
  --method tools/list
```

Llame a una herramienta de la misma forma:

```bash
npx @modelcontextprotocol/inspector --cli https://app.lobbystack.com/api/mcp \
  --transport http \
  --header "Authorization: Bearer $LOBBYSTACK_API_KEY" \
  --method tools/call --tool-name get_business
```

## Cree su propio cliente

Los SDK oficiales de MCP se conectan con unas pocas líneas. En TypeScript:

```ts
import { Client, StreamableHTTPClientTransport } from "@modelcontextprotocol/client";

const client = new Client({ name: "my-app", version: "1.0.0" });
await client.connect(new StreamableHTTPClientTransport(new URL("https://app.lobbystack.com/api/mcp"), {
  requestInit: { headers: { Authorization: `Bearer ${process.env.LOBBYSTACK_API_KEY}` } },
}));

const result = await client.callTool({ name: "list_messages", arguments: { status: "open" } });
console.log(result.structuredContent);
```

Si está escribiendo código en lugar de usar un asistente, la [API REST](/es/api/overview) le da los mismos datos con HTTP simple.
